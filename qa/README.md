# WT8 clean-room QA

This directory contains executable golden evidence derived only from the approved clean-room specifications and `MOVE_AI_DATA_PACK/APP_USED_DATA`.

The committed fixtures are regenerated by `scripts/qa/generate-approved-goldens.mjs`. The generator:

- verifies every approved specification and numbered input hash before reading workbook cells;
- never reads the quarantined reference HTML;
- reconstructs the model, network-identity, and CVaR goldens from approved workbook tables;
- writes canonical UTF-8/LF JSON; and
- fails instead of adopting an unknown or modified input.

The generator uses the bundled spreadsheet runtime supplied by Codex. It is intentionally not part of application runtime dependencies. The default test suite validates the committed output, source hashes, and public contract surface.

The gateway oracle follows the approved WT2/WT3/WT6 authority: `move-ai/gateway/v1`, exact expanded meta/error keys, `reference` as a domain state rather than a data mode, and `tuningRun` as the typed gateway method.
