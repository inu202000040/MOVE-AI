# MOVE AI 텍스트 전용 구현 패킷

## 1. 목적

이 폴더는 승인된 완성 애플리케이션을 블랙박스 방식으로 관찰해 작성한 구현자용 텍스트 계약이다. 구현자는 과거 애플리케이션, 저장소, 실행 번들 또는 화면 캡처를 보지 않고 이 문서와 승인 데이터만 사용한다.

관찰일은 2026-08-13이다. 관찰 대상은 화면에 보이는 문구, 수치, 배치, 상태와 사용자 상호작용뿐이다.

## 2. 구현 입력

구현자가 사용할 수 있는 입력은 다음으로 제한한다.

1. 이 폴더의 WT1~WT6 문서.
2. `../docs/specs`의 clean-room 계산·데이터 계약.
3. `MOVE_AI_DATA_PACK`의 승인 데이터.
4. 동결된 공통 DTO와 route 계약.
5. 사용하는 라이브러리의 공식 문서와 정식 배포 패키지.

## 3. 제외 입력

- 과거 애플리케이션 소스와 Git 기록.
- 과거 저장소명, URL, 커밋 식별자와 파일 경로.
- 실행 번들, source map, 스타일 원문과 마크업 원문.
- 과거 애플리케이션의 캡처 이미지.
- 다른 화면에서 복사한 그래픽 코드와 벡터 경로.

## 4. 문서 우선순위

1. 이 폴더에 기록된 보이는 결과와 상태 전이.
2. `../docs/specs`의 계산·데이터·반응형 계약.
3. 승인 데이터 팩의 실제 값과 단위.
4. 공식 라이브러리 문서.

충돌하면 새 기능을 발명하지 않는다. 보이는 결과의 충돌은 이 폴더, 계산과 데이터 충돌은 승인 데이터 및 동결 계약을 우선한다.

## 5. 화면 검수

- 1440×900: 데스크톱 주 기준.
- 375×812: 모바일 주 기준.
- 900×900: shell 전환과 열 구성 smoke.
- 640×900: compact 구성과 overflow smoke.

1440과 375는 문구·순서·기능을 모두 검수한다. 900과 640은 열 전환, 숨김, drawer, modal과 가로 overflow를 검수한다.

## 6. 자동 실패

- 기존 코드나 스타일을 구현 입력으로 사용함.
- 화면에 없는 기능·카드·배지·문구를 추가함.
- fixture, stale 또는 reference를 LIVE로 표시함.
- 핵심 계산 golden 값이 다름.
- 375px에서 document 전체 가로 스크롤이 발생함.
- WebGL2 정상 환경의 Network가 3D globe가 아님.
- 그래픽 실패 시 사용 가능한 2D fallback이 없음.
- route, 대표모델 또는 튜닝 결과의 화면 간 전달이 끊김.
- 실제 브라우저 검증 없이 완료 처리함.
